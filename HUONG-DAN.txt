HƯỚNG DẪN ĐƯA WEBSITE LÊN MẠNG & TỰ CẬP NHẬT
Website MC song ngữ & Phiên dịch Nhật – Việt – Hồ Thị Hằng
=====================================================

CẤU TRÚC THƯ MỤC
- index.html ............ Trang chủ (giữ nguyên thiết kế)
- cam-on.html ........... Trang "Cảm ơn" hiện ra sau khi khách gửi form liên hệ
- data/highlights.json .. Danh sách "Sự kiện tiêu biểu"
- data/gallery.json ..... Danh sách "Hình ảnh hiện trường tiêu biểu"
- data/testimonials.json  Danh sách "Đánh giá của khách hàng"
- images/ ............... Ảnh (ảnh mới tải lên qua trang quản trị nằm trong images/uploads)
- admin/ ................ Trang quản trị để bạn tự thêm sự kiện, ảnh, đánh giá

-----------------------------------------------------
PHẦN A – ĐƯA WEBSITE LÊN MẠNG (làm 1 lần, khoảng 15–20 phút)
-----------------------------------------------------

BƯỚC 1. Tạo tài khoản GitHub (miễn phí): https://github.com/signup

BƯỚC 2. Sửa 1 dòng trong file admin/config.yml
  Mở file bằng Notepad / TextEdit, tìm dòng:
      repo: TEN-GITHUB-CUA-BAN/hang-mc-website
  Thay TEN-GITHUB-CUA-BAN bằng tên tài khoản GitHub của bạn. Lưu lại.

BƯỚC 3. Tạo kho chứa (repository) trên GitHub
  - Bấm dấu "+" góc trên bên phải → "New repository"
  - Repository name: hang-mc-website   (đặt đúng tên này)
  - Chọn Public → bấm "Create repository"
  - Bấm dòng "uploading an existing file"
  - Kéo TOÀN BỘ nội dung bên trong thư mục hang-mc-website (không kéo thư mục ngoài cùng)
    vào ô tải lên → bấm "Commit changes"

BƯỚC 4. Đưa lên Netlify (miễn phí)
  - Vào https://app.netlify.com/signup → chọn "Sign up with GitHub"
  - "Add new site" (hoặc "Add new project") → "Import an existing project" → chọn GitHub
    → chọn kho hang-mc-website
  - Build command: để trống. Publish directory: để trống (hoặc dấu chấm ".")
  - Bấm Deploy. Vài giây sau bạn có địa chỉ dạng https://ten-gi-do.netlify.app
  - Đổi tên cho đẹp: Site configuration → Change site name (ví dụ: hang-mc → https://hang-mc.netlify.app)

BƯỚC 5. Tạo "chìa khóa đăng nhập" cho trang quản trị
  5a. Trên GitHub: ảnh đại diện → Settings → Developer settings → OAuth Apps → New OAuth App
      - Application name: Hang MC Admin
      - Homepage URL: địa chỉ Netlify của bạn (ví dụ https://hang-mc.netlify.app)
      - Authorization callback URL: https://api.netlify.com/auth/done
      - Bấm Register application → copy "Client ID"
      - Bấm "Generate a new client secret" → copy "Client secret" (chỉ hiện 1 lần)
  5b. Trên Netlify: vào site → Site configuration → Access & security → OAuth
      → Install provider → chọn GitHub → dán Client ID và Client secret → Install

BƯỚC 6. Bật nhận tin nhắn từ form liên hệ
  - Netlify → site → Forms → Enable form detection
  - Sau đó vào Deploys → Trigger deploy → Deploy site (để Netlify nhận diện form)
  - Muốn nhận email khi có khách gửi form: Forms → Form notifications → Add notification
    → Email notification → nhập email của bạn

-----------------------------------------------------
PHẦN B – TỰ CẬP NHẬT SAU MỖI SỰ KIỆN
-----------------------------------------------------
  1. Mở: https://(địa-chỉ-web-của-bạn)/admin
  2. Bấm "Login with GitHub"
  3. Chọn mục cần sửa:
     - "Sự kiện tiêu biểu (timeline)"  → bấm Add → điền Năm.Tháng, tên tiếng Việt, tên tiếng Nhật, vai trò
     - "Hình ảnh hiện trường tiêu biểu" → bấm Add → tải ảnh lên, điền Năm.Tháng và chú thích 2 thứ tiếng
     - "Đánh giá của khách hàng"        → bấm Add → dán lời đánh giá và bản dịch
  4. Bấm "Publish" (hoặc Save → Publish). Khoảng 1 phút sau trang web tự cập nhật.

  Ghi chú:
  - Năm.Tháng viết theo dạng 2026.11 để trang tự sắp xếp đúng thứ tự.
  - Timeline xếp từ cũ → mới; Hình ảnh xếp mới nhất lên đầu.
  - Ảnh nên chụp ngang, dung lượng dưới 1 MB để trang tải nhanh.
  - Muốn sửa phần chữ cố định (giới thiệu, dịch vụ, quy trình...), hãy nhờ Claude sửa file index.html.

-----------------------------------------------------
PHẦN C – (TÙY CHỌN) TÊN MIỀN RIÊNG
-----------------------------------------------------
  Nếu sau này mua tên miền (ví dụ hothihang.com), vào Netlify → Domain management → Add a domain
  và làm theo hướng dẫn. Nhớ cập nhật lại "Homepage URL" trong OAuth App trên GitHub (Bước 5a).
